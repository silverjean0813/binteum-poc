# 빈틈 품질 확인 PoC

혼잡도 제보 저장 및 품질 기준을 직접 확인하기 위한 프로토타입입니다.

## 1. 주요 기능

- 카페별 혼잡도 조회
- 혼잡도 제보 저장
- 동일 카페의 10분 이내 중복 제보 방지
- 로그인하지 않은 사용자의 제보 제한
- 데이터 부족 상황 안내
- 조회 응답 시간 측정
- 품질 기준을 화면에서 확인

## 2. 품질 기준

| 기준 | 값 |
|---|---|
| 중복 제한 시간 | 10분 |
| 혼잡도 최소 제보 | 3건 |
| 혼잡도 유효 시간 | 최근 15분 |
| 조회 응답 기준 | 3초 이내 |

## 4. 테스트 방법

### 정상 상황
1. 카페를 선택합니다.
2. 데이터 상태를 `정상 데이터 (3건 이상)`으로 선택합니다.
3. `혼잡도 조회` 버튼을 클릭합니다.
4. 혼잡도와 응답 시간이 표시되는지 확인합니다.

### 데이터 부족 상황
1. 데이터 상태를 `정보 부족`으로 변경합니다.
2. `혼잡도 조회` 버튼을 클릭합니다.
3. 임의의 혼잡도를 표시하지 않고 안내 메시지가 나타나는지 확인합니다.

### 중복 제보 상황
1. 로그인 사용자를 선택합니다.
2. 카페와 혼잡도를 선택합니다.
3. `제보 저장`을 클릭합니다.
4. 동일한 카페에 다시 제보합니다.
5. 중복 제보 안내와 현재 저장된 제보 건수를 확인합니다.

## 5. 프로젝트 목적

과제 1에서 정의한 품질 기준을 과제 2의 비즈니스 로직과 연결하고,
실제 동작하는 PoC에서 해당 기준을 확인할 수 있도록 구현했습니다.
